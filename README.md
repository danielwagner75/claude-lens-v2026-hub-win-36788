## About Claude Lens

Claude Lens is built for people who want a clearer view of Claude Code usage without relying on a remote service. It presents activity in a local web interface so you can review sessions, follow spending trends, and inspect operational details from one place.

The dashboard is especially useful when you want quick insight into token costs, cache behavior, and tool usage over time. With daily breakdowns and session-focused views, it helps turn raw activity into something easier to scan, compare, and act on.
